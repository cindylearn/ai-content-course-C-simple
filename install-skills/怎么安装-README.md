# 怎么安装 + 怎么开始

这个 `install-skills/` 里有 **7 个 skill（01-07）**，每个都能单独调用。
> 🔴 **`00-setup`（安装助手）在仓库根目录单独放**——**课前先装它 + 跑它**（链接 `…/tree/main/00-setup`）把工具/连接器装好；**地基不在 00 做**。`install-skills`（01-07）**开工时用到哪个装哪个（一个一个，别一次装全）**。

## 一、装
- **课前**：装根目录的 `00-setup`（跟 Claude 说「帮我从这个链接装这个 skill」/ 或下载后把 `00-setup` 拖进 `~/.claude/skills/`）→ 跑它「帮我安装」把工具/连接器弄好。
- **课上 · 一个一个装**：要做哪个 skill，就装哪个 —— 跟 Claude 说「帮我从这个链接装这个 skill」+ 那个 skill 的链接（`…/install-skills/0X-name`），或把那个文件夹拖进 `~/.claude/skills/`。**用到哪个装哪个、不用一次装全。**（想一次装齐也行 → 在本文件夹终端 `bash 一键安装.sh`，可选。）

## 二、怎么开始（触发 · 两种方式）

🔴 **课前 → 先触发 `00`（纯装机）** 把工具装好、账号连好；**开工（第一次 / 新业务）→ 从 `01` 开始**，01 会带你先打地基（定落脚点 → 建业务档案 → 搭 Notion 大脑）再定品牌地基。**地基不在 00 做，在 01 做。**

| # | Skill（安装文件夹）| 方式一 · 斜杠 | 方式二 · First Prompt（打这句话） |
|---|---|---|---|
| 00 | 00-setup（根目录·课前装）| `/suma-ai-00-setup` | 帮我安装（装工具 + 连账号 + 装 skill）|
| 01 | 01-branding | `/suma-ai-01-branding` | 帮我从零搭我的 AI 内容营销系统（定落脚点、建 Notion 大脑、品牌定位/受众/红线）|
| 02 | 02-copy | `/suma-ai-02-copy` | 帮我写广告文案 |
| 03 | 03-image | `/suma-ai-03-image` | 帮我出海报／产品图 |
| 04 | 04-video-avatar | `/suma-ai-04-video-avatar` | 帮我做口播短视频（含数字人：AI人／真人样子／卡通人）|

> 想一个 skill 走完全程 → 用 **07**；想一步一步来 → 课前 **00 装机**，开工 **01→02→…→07**。

🔴 每个 skill 都会：一题一题问（选项卡）· 开工前先确认地基在不在（没有 → 回 **01**）· 强制记录业务 md · 出的东西套大师+NLP+人性需求。
