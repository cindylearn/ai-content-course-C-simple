# 怎么安装 + 怎么开始

这个 `install-skills/` 里有 **8 个 skill（01-08）**（含 05 · AI 剪辑），每个都能单独调用。
> 🔴 **`00-setup`（安装助手）在仓库根目录单独放**——**课前先装它 + 跑它**（链接 `…/tree/main/00-setup`）把工具/连接器装好；**地基不在 00 做**。`install-skills`（01–08）**课上一次过装整包**（一个链接，装完**重开 Claude**）；之后**每步用触发词**启动对应 skill。

## 一、装
- **课前**：装根目录的 `00-setup`（跟 Claude 说「帮我从这个链接装这个 skill」/ 或下载后把 `00-setup` 拖进 `~/.claude/skills/`）→ 跑它「帮我安装」把工具/连接器弄好。
- **课上 · 一次过装整包**：跟 Claude 说「帮我从这个链接装 install-skills」+ 链接（`…/install-skills`），或本文件夹终端 `bash 一键安装.sh`，或把整个 install-skills 拖进 `~/.claude/skills/`。**装完重开 Claude** 让全部生效。之后**每个 skill 用它的触发词启动**：①答完一个直接说下一个触发词接着做，或②单独触发。（个别 `…/install-skills/0X` 链接只当备份，装漏才用。）
