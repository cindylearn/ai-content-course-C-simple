# 00 · 无脑安装向导（学员 setup · Mac + Windows）

> 这份给「完全不懂技术」的学员用。你（Claude）按这个带 —— **一次一步、做完再下一步、绝不一次全倒**；每步帮他验证。
> 🔴 **最高铁律「说人话」**（跟 SKILL.md 顶部那条一致）：**绝不报技术名词**（Homebrew/node/python/pillow/ffmpeg/sudo…）· **绝不甩命令给学员自己跑**（尤其 `curl … | bash`）· 工具**你自己跑本地脚本**装 · 要学员做的只有「点同意 / 打一次电脑密码 / 点浏览器允许」，每样一句大白话。
> 目标：**学员手动只剩「点几下 + 打一次电脑密码」，其余全你自动。**

---

## 学员总共只亲手做这几件（其余你全自动）
1. **课前**：装 **Claude 桌面 App** + 装 **git**（这两样你替不了，得他自己装好，装好打开就能跟你讲话）。
2. 注册要用的账号（缺哪个注哪个）。
3. 点授权连 3 个连接器（Notion / Higgsfield / ChatCut）。
4. 装工具时**打一次电脑密码**、连 Drive 时点一次浏览器**「允许」**。
> 其余（装工具、装 skill、搭骨架）你帮他自动 —— 但 **skill 一个一个装：用到哪个装哪个**，别一次装全。

---

## Step 0 · 课前先装好这两样（学员自己弄，你替不了）
- **① Claude 桌面 App**：去 **https://claude.com/download** 下载电脑版 → 装好 → 注册 → 订阅（US$20/月，可退）。⚠️ 要**桌面 App**，不是只用网页。（学员能跟你讲话 = 已装好 ✓）
- **② git**（装完 Claude 第一件事，最重要）：
  - **Mac**：打开「终端」跑一下 `xcode-select --install` → 弹窗点「安装」等完；或去 **https://git-scm.com/install/mac** 装。
  - **Windows**：去 **https://git-scm.com/install/windows** 下载装好 → 重开一次终端。
  > 跟学员就说「这两样装好、能打开 Claude 跟我讲话，就来找我，其余我帮你」。**没 git 后面会卡**，先弄好。

## Step 1 · 你帮他把工具装好（学员不碰命令）
学员说「帮我把工具装好」→ **你自己跑本地脚本**（别叫他打、别 `curl` 网上的）：
- **Mac**：`bash ~/.claude/skills/00-setup/setup-tools.sh`
- **Windows**：`powershell -ExecutionPolicy Bypass -File ~/.claude/skills/00-setup/setup-tools.ps1`

跟学员只说一句：「**我帮你把需要的工具装好，中途会弹出要你打电脑密码，打一下按 Enter —— 屏幕不显示字是正常的。**」
- Windows 装完 → 提醒他**重开一次终端**再继续。
- 🔴 **别报 Homebrew/node/python 这些名字、别把脚本步骤念出来解释。** 装完说「✓ 工具好了」就行。

## Step 2 · 连远程连接器（点授权，就点几下）
这些是**远程连接器**，不用装任何东西，只需登录自己账号点授权。一个一个带，别一次全给：

| 连什么 | 你怎么带他 |
|---|---|
| **Notion** | Claude 设置 → Connectors → 搜 "Notion" → 点 Connect → 浏览器点「允许」 |
| **Higgsfield** | 添加自定义连接器 → 贴 `https://mcp.higgsfield.ai/mcp` → 允许 |
| **ChatCut**（要剪片才连）| 添加自定义连接器 → 贴 `https://api.chatcut.io/api/external-mcp/mcp` → 允许 |

- **Suno**：网页 suno.com 用，不用连。**Google Drive / GitHub**：要归档 / 装 skill 才连。

## Step 3 · 装 skill —— 用到哪个装哪个（别一次装全）
- **课前**：只装 `00-setup`（就是现在这个）。
- **开工**：要做哪个才装哪个 —— 跟你说「帮我从这个链接装这个 skill」+ 那个 skill 的链接（`…/install-skills/0X-name`）。**不用一次把 01-07 全装。**
- 🔴 装机（00）到此为止：**定落脚点 / 建业务档案 / 搭 Notion 大脑 / 品牌地基，全是 `01-branding` 的活**，开工打 `/suma-ai-01-branding` 再做。

## Step 4 · 验证全绿
帮他逐个 test：Notion 读得到？Higgsfield 出得了图？工具装好了？全绿 = 课前完成。
