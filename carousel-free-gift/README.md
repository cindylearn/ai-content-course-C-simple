# 🎠 AI Carousel 图文帖产生器

做 IG／小红书 **carousel 轮播图**的 skill。
教练式一题一题问你，配好版型和颜色，**先出样张给你看**，你说 OK 才生成整组图。

## 它会怎么带你

**全部是选择题，一题一题问，每题 5–10 个选项。**
按你的答案走分支，实际大约问 25–35 题（不是每题都问）。

| 阶段 | 在干嘛 |
|---|---|
| **开工** | 你的品牌资料在哪 · 做哪个业务 · 做哪一件内容 · 成品放哪（Notion／本机／Drive 分开问） |
| **内容** | 完全没 idea？→ 走**选题引擎**：先让你教我你的行业 → 631 比例 → 八大主题 → 拆你的对标帐号 → 挖你订阅的电子报 → 搜最新行业资讯 → 出 5–8 个题目给你挑 |
| **版型** | 11 个维度**各选各的**（底材／字体／繁简／位置／对齐／容器／标题色／描边／调色／编号／装饰） |
| **样张** | 🔴 **先出一张给你看**，你说对了才往下 |
| **颜色** | 四件套分开问，而且**在真的底图上验证**（纯色底好看的颜色压到照片上可能糊掉） |
| **内容** | 每一张的完整文案写出来 → 落 Notion → **你说 OK 才出图** |
| **CTA** | 9 种形式给你挑（不是只有留言暗号） |
| **出图** | 1080×1350 PNG，要更清晰可设 2 倍 |

## 几条它会帮你守住的规则

- **封面中间那行大字必须是「名词」** ＝ 一个可以被拿走的东西。写不出名词，代表这条内容还没想清楚要给人家什么。
- **一组只讲一个 formula**。塞太多就拆成系列，一集一个 —— 但绝不偷下一集的料来填。
- **内页给「可以直接抄去用的句式」，不是定义。** 投影片结构搬进 carousel 会变成三行填空表，没人看完。
- **选留言暗号前先过「拿不到检查」**：图里给的 和 留言换的，差在哪？讲不出来就别用留言型。
- **一份赠品一个暗号，绝不共用。** 两份不同的东西共用一个字，你分不出观众要哪一份。
- **学对标只借结构和机制** —— 版式、容器、单色贯穿、吊胃口的做法。
  **你自己的识别元素（专属手绘图案／配色／handle／字体）一律不动**，那正是让人认出你的东西。
- **不编造数据、不做假见证**、不承诺做不到的事。

## 第一次用要做的一件事

把你的品牌填一次，存成 `BRANDS.md` 放 skill 同一层（格式在 SKILL.md 的「品牌预设」那节）。
之后每次开工它会先读，你不用重讲。
