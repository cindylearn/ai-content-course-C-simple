## 📸 照片从哪里来（先看这段，最容易卡在这里）

carousel 的底图有**两条路**，skill 会先问你走哪条：

| | Ⓐ 自己准备 | Ⓑ AI 生成 | Ⓒ 不用照片 |
|---|---|---|---|
| 花什么 | **0 元** | **要 credit**（Higgsfield 是付费工具） | **0 元** |
| 怎么做 | 自己拍／找旧照 | 丢 3–5 张真实照片锁脸，用文字描述场景 | 纯色底／纸质底 |
| 卡在哪 | 手上常常**没有一张构图对的**（自拍多半人在正中间，没地方放字） | 要钱、要试几轮 | — |

🔴 **选 Ⓐ 的话，翻相册找「人不在正中间」的照片** —— 人靠左或靠右、另一边是墙／天空／地板这种干净的空。
找不到就拍一张：手机架远一点、人站旁边。这一张构图对不对，决定整组好不好看。

🔴 **选 Ⓑ 的话**，要先有 [Higgsfield](https://higgsfield.ai) 帐号跟余额。
**skill 会在生图前先报价给你**（用哪个模型／生几张／单价／总共多少），
**你说「生」它才跑**，跑完立刻回报实际扣了多少。不会先生了再讲钱。

参考行情：只做 1 组 → 4 张约 4 credits 就够；打算长期做系列才值得训练锁脸模型（一次性约 305 credits）。

## 它会怎么带你

**全部是选择题，一题一题问，每题 5–10 个选项。**
按你的答案走分支，实际大约问 25–35 题（不是每题都问）。

| 阶段 | 在干嘛 |
|---|---|
| **开工** | 你的品牌资料在哪 · 做哪个业务 · 做哪一件内容 · 成品放哪（Notion／本机／Drive 分开问） |
| **内容** | 完全没 idea？→ 走**选题引擎**：先让你教我你的行业 → 631 比例 → 八大主题 → 拆你的对标帐号 → 挖你订阅的电子报 → 搜最新行业资讯 → 出 5–8 个题目给你挑 |
| **版型** | **13 个维度各选各的**（底材／字体／繁简／垂直位置／横向对齐／容器／标题色／描边／照片调色／编号／**标签位置**／**疏密**／装饰） |
| **样张** | 🔴 **先出一张给你看**，你说对了才往下 |
| **颜色** | 四件套分开问，而且**在真的底图上验证**（纯色底好看的颜色压到照片上可能糊掉） |
| **素材** | 照片走哪条路（见上）· 几张照片打全组（预设 1–2 张，最省也最统一） |
| **内容** | 每一张的完整文案写出来 → 落 Notion → **你说 OK 才出图** |
| **CTA** | 9 种形式给你挑（不是只有留言暗号） |
| **caption** | 🎣 **7 种 hook 挑一个**，第 2–4 段照填空模板 |
| **出图** | 1080×1350 PNG，要更清晰可设 2 倍 |

## 🎣 caption hook 库

写 caption 最花时间的其实只有开头两行。这个 skill 内建 7 种 hook，挑一个套：

| | 类型 | 靠什么抓人 |
|---|---|---|
| ① | 换病因 | 把他以为的原因换掉 |
| ② | 自曝糗 | 我也烂过，所以我懂 |
| ③ | 对比反差 | 两个人的差距 |
| ④ | 行业揭秘 | 内行才知道的事 |
| ⑤ | 自问自答 | 引号自问自答，对话感最强 |
| ⑥ | 借口清单 → 反转 | 三个借口一行列完，再说「我三个都没解决」 |
| ⑦ | 从画面讲起 → 拆穿 | 先讲成品多厉害，再讲实际多随便 |

后面第 2–4 段（给公式／指向图＋CTA／hashtag）是**壳**，换主题填新内容就好。
🔴 同一个系列**别连着用同一种 hook** —— 九宫格会看起来像同一篇发四次。

## 几条它会帮你守住的规则

- **封面中间那行大字必须是「名词」** ＝ 一个可以被拿走的东西。写不出名词，代表这条内容还没想清楚要给人家什么。
- **一组只讲一个 formula**。塞太多就拆成系列，一集一个 —— 但绝不偷下一集的料来填。
- **内页给「可以直接抄去用的句式」，不是定义。** 投影片结构搬进 carousel 会变成三行填空表，没人看完。
- **内页每行别超过约 20 个中文字**，超过就折行，一折行整张立刻变挤。写不下要砍字，不是缩字级。
- **选留言暗号前先过「拿不到检查」**：图里给的 和 留言换的，差在哪？讲不出来就别用留言型。
- **一份赠品一个暗号，绝不共用。** 两份不同的东西共用一个字，你分不出观众要哪一份。
- **要花钱的事先报价再做**（生图／训练模型），你说「生」才跑。
- **学对标只借结构和机制** —— 版式、容器、单色贯穿、吊胃口的做法。
  **你自己的识别元素（专属手绘图案／配色／handle／字体）一律不动**，那正是让人认出你的东西。
- **不编造数据、不做假见证**、不承诺做不到的事。

## 档案

```
SKILL.md               主档（流程 · 铁律 · 提问总表 54 题 · caption hook 库）
assets/carousel.html   出图模板 —— 只改最上面 CONFIG 和 SLIDES 两个区块
scripts/screenshot.mjs 把每一张截成 1080×1350 PNG
BRANDS.md.example      品牌预设范本 → 复制成 BRANDS.md 填一次
```

装好之后 `assets/carousel.html` 里已经有一组 **4 张的示范内容**，
直接跑 `node scripts/screenshot.mjs demo` 就能看到成品长什么样。

## 第一次用要做的一件事

```bash
cp BRANDS.md.example BRANDS.md
```

把你的品牌填进去（色号／handle／内容线／受众／红线／落脚点）。
之后每次开工 skill 会先读它，你不用重讲一遍。
