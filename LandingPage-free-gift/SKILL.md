# ai-onepage-lp —— 答几题选择题，做出一个会成交的销售单页

> 这是 SUMA【AI 内容营销课】现场**录视频见证送的大礼**。
> 目标：让完全不懂 code 的人，也能做出一个**像 SUMA 官方落地页那样**会成交的销售单页。

## 🧱 铁律（每次都守）

1. **先问业务、再读 md、再收图，最后才答题。** 🔴 **第一题永远是「这次做哪个业务？」**（Step 0，不可跳过、不准自己猜、不准直接把扫到的业务当预设套上去）。业务定了才去找 01-branding 建的**品牌/业务 md**，能读到的（品牌名/色/logo/受众）就**别再问**；再收素材袋；最后才答题。顺序＝**A 问业务 → B 问页型 → C 读 md＋收图 → D 答题 → E 出 hero 样张 → F 铺全页**。跳过 A 会拿错品牌色做错受众；跳过 B 会拿卖东西的结构去做一张不卖东西的页；跳过 C 会做出「全是字没有图」的页。
2. **一题一张选项卡**（用 `AskUserQuestion`），能做选项就做选项，绝不一次把所有题倒给用户。每题 ≤4 个选项 +「其他」。只有产品名/价格数字/见证原文这种非打字不可的才让他打字。
2b. 🔴🔴 **绝不 skip 提问 —— 一题一题问完为止。**
   - **「只是 test 一下」「随便跑跑看」「先看看效果」都不是 skip 的理由。** 他要看的就是这个 skill 问得够不够好，你跳过提问＝把要测的东西测掉了。
   - **不准自己脑补答案往下做**（自己挑行业、自己挑痛点、自己定价、自己选配色 = 违规）。查到的资料只能当**选项**给他挑，不能当预设直接套。
   - **他没答的题不准算过。** 他跳过／关掉卡片 → 那题**再问一次或明确记成「跳过」**，不是你替他决定。
   - 唯一能少问的：**读得到品牌 md** 的那几题（`[读md或问]`），以及**页型分流后不适用**的题（例：免费闸门页不问价格）—— 这两种叫「按条件不问」，不叫 skip，而且要**讲一句**为什么不问。
   - **自检**：生成前回头数一遍——素材袋 6 样问完没？内容题该问的问完没？**有一样没问就回去问，不准先生成。**
3. **两版都要出**：① AutoCRM 片段（贴进后台）② 独立页（能直接上线）。见「输出规格」。
4. **图片零门槛**：学员只丢图，我自动压缩 + base64 内嵌 → 两版都自包含、永不裂图、加载快。视频不内嵌，改贴链接。
5. **护栏（真实第一）**：
   - ✅ 学员**自己的生意**该报价就报价、该做限时就做限时——那是他的商业决定（**不套 SUMA 招生的合规房规**）。
   - ❌ 绝不编造：假见证、假数字、假成果承诺、假紧迫（没名额别写「仅剩 3 位」）。
   - ❌ AI 生成图有红线（见 Step 1）。
6. **不碰后台**：这个 skill 只做**静态销售单页**。dashboard / 会员系统 / 自动跟进 / CRM / 支付集成 = **Jared 的 AI Business 课**，故意不做（见结尾）。

## 📋 流程

### Step 0 · 🔴 这次做哪个业务？（第一题，不可跳过）

**开场第一句就问这题。** 在这题答完之前，**不准**套用任何品牌名、品牌色、logo、受众、红线。

先**静默扫**一遍有哪些业务（业务档案 md / 成品 folder / Notion / Drive），扫完**不要抢答**，
拿去当选项。用 `AskUserQuestion` 出选项卡，`header: 做哪个业务`：

- 扫到的业务**逐个列**（description 用一句话带出它是做什么的、卖给谁）
- 补一个 **「新业务」**（description：我帮你建一份业务档案，之后每次直接用）
- 补一个 **「帮客户做」**（description：不进你自己的业务库，只用这次）
- 业务超过 3 个 → 只列**最常用的 3 个**，其余让他用 Other 打字

**什么都扫不到也不要卡住** —— 选项就三个：「新业务（建档）」／「帮客户做」／「一次性（不建档）」。

---

**接下来照他选的走：**

| 他选 | 你要做什么 |
|---|---|
| **已有业务** | 读该业务的 md，把**品牌名／品牌色／logo／受众／红线**摊出来给他确认一眼：「我会用这些，对吗？有要改的现在讲。」→ 确认了才往下，下面标 `[读md或问]` 的题**全部跳过** |
| **新业务** | 🔴 **不要自己 inline 建档就算了** —— 再问一题分岔（见 Step 0a） |
| **帮客户做／一次性** | 走 Step 0a 的 B（最小档案），并标记**不进你自己的业务库**，只用这次 |

🔴 **共同底线**：品牌色、受众、身份 —— **一律是他讲的算**，不是你从别处捞来直接用。

---

#### Step 0a · 🔴 新业务 → 要不要先打地基？（分岔题，一题一张卡）

新业务**不是问三题就够**。品牌地基（落脚点／persona／红线／命名／logo／内容路线）是
**01-branding** 这个 skill 的活，做一次以后每个 skill 都能直接用 —— 但一个只想做一张 LP 的人
被硬塞进完整地基会跑掉。所以**给他选**，`header: 新业务怎么走`：

| 选项 | 你要做什么 |
|---|---|
| **A 先打地基（推荐）** | 转去 **`01-branding`**：定落脚点 → 建业务档案 md → 搭 Notion 大脑 → 受众／persona／红线／命名／logo／两条内容路线。<br>**做完回到这个 skill 继续**，回来时业务档案已经在，Step 0 直接降级成确认题 |
| **B 先做这次的，档案后补** | 只问最小三题：**① 品牌名　② 一句话讲你做什么生意　③ 卖给谁** → 写成业务 md 存起来（存哪跟他确认）→ 往下做。<br>收尾时提醒一句：「地基还没打，之后跑 `01-branding` 补上，下次每个 skill 都省事。」 |

🔴 **B 不是偷懒版，是入口版**：最小三题也**一定要落成 md**（帮客户做／一次性除外），
否则下次进来又从零问一遍。

---

#### Step 0b · 读品牌资料（业务定了之后，能免则免）

业务确认完，才去读 **01-branding 建的品牌/业务 md**（一般在成品 folder / Notion，
里面有品牌名·品牌色·logo·受众）。

- **读到了** → 直接用，跳过下面 `[读md或问]` 那几题。
- **读不到 / 学员没上过 01** → 下面标 `[读md或问]` 的（Logo · 卖给谁 Q2 · 配色 Q10 · 品牌名）照常问。

> 目的：上过课的学员，品牌地基已经建好，**不重复问**＝更无脑。

### Step 0c · 🔴 这张页要干嘛？（页型分流 · 决定哪些区块存在）

🔴 **这个 skill 不是只会做销售页。** 页型不问清楚，就会拿卖东西的结构（价格／原价删除线／
紧迫感／价值堆叠）去做一张根本不卖东西的页 —— 整页要重来。用 `AskUserQuestion`，`header: 这张页要干嘛`：

| 页型 | 什么时候用 | 落点 | 有哪些区块 |
|---|---|---|---|
| **A 销售页** | 直接卖产品／课程／服务，页上成交 | 付款／报名／WhatsApp 谈 | 全部 9 区块（含价格＋紧迫＋价值堆叠） |
| **B 闸门页**（换名单） | 免费资料包／懒人包／模板，用东西换联络方式 | 表单 → 资料包 → 社群 | ❌ 删价格·紧迫·价值堆叠　✅ 换成「你会拿到什么」＋「这份是怎么来的」＋表单 |
| **C 活动报名页** | Webinar／公开课／Open Day 报名 | 报名表单 | ❌ 删价值堆叠　✅ 加时间地点·讲师·议程；免费场不放价格，收费场才放 |
| **D 预约咨询页** | 先聊再成交（顾问／服务型／高单价） | 预约时段／WhatsApp | ❌ 删价格·价值堆叠　✅ 加「聊什么·要多久·会不会被硬销」打消顾虑区 |

**照页型决定后面问什么**（这叫**按条件不问**，不是 skip —— 而且要跟他讲一句为什么不问）：

| 页型 | 价格题(Q6) | 紧迫题(Q7) | 额外要问 |
|---|---|---|---|
| A 销售页 | ✅ 问 | ✅ 问 | — |
| B 闸门页 | ❌ 不问（免费） | ❌ 不问（免费的东西做假限时＝红线） | 资料包**叫什么名字**（要跟封面／资料包／页面标题三处一致）· 拿到之后**去哪**（社群链接） |
| C 活动报名页 | ⚠️ 免费场不问，收费场才问 | ✅ 问（真名额／真截止才写） | 日期·时间·线上还是线下·地点／Zoom·讲师是谁 |
| D 预约咨询页 | ❌ 不问 | ⚠️ 只问「档期有限」这类真的写得出的 | 聊多久·怎么聊(WhatsApp／Zoom／见面)·会不会收费 |

### Step 1 · 先收「素材袋」（开工前，一样一样问）

开场先说一句，让学员心里有数：

> 「做一个像样的页，先准备几样图片就好。我一样一样问你，有就丢给我，没有的我可以帮你处理。」

然后**一样一样过**（每样都用选项卡问「有 / 没有 / 跳过」）：

| 素材 | 要几个 | 放页面哪里 |
|---|---|---|
| **Logo**（PNG 透明底最好）`[读md或问]` | 1 | 顶部 header |
| **主视觉**（hero 大图，或短视频链接） | 1 | 首屏 |
| **卖点图**（每个卖点一张） | 3–6 | 模块卡 |
| **主角/团队照**（个人IP、服务型必备） | 1–4 | 讲师/信任区 |
| **真实见证**（截图，或 名+一句话） | 2–6 | 见证区 |
| **案例数据**（有才放：before→after 数字） | 可选 | 案例卡 |

**🅰️ 每样「没有图」时，问一句：要不要我用 Higgsfield 帮你生成？**（选项卡：① 用 AI 生成 ② 用占位/纯文字兜底 ③ 之后再补）

**AI 生成的红线（务必守）：**
- ✅ **可生成**：主视觉背景、场景图、氛围/概念/装饰图、抽象配图。
- ❌ **不可假造**：真实产品照（不能凭空编个假产品外观）、学员本人的脸（真人只能用真照；顶多做明显风格化的头像）、**见证头像/见证人——绝不造假**（假见证＝红线）。
- 生成前先跟学员讲清楚「这张是 AI 配图，不是你的真实产品/真实客户」，他同意才生成。

> 生成用连接器里的 Higgsfield（课程 00-setup 已授权）。缺料也能先做——缺的位子用占位或纯文字兜底，之后替换，不卡流程。

### Step 2 · 答题（选择题优先，一题一张卡）

按顺序问，能选就选：

| # | 题 | 类型 | 选项 | 何时问 |
|---|---|---|---|---|
| 1 | 你卖什么？先选**行业** | 选择 | 电商 / 美妆美容 / 补习教育 / 服装 / 保险顾问 / 餐饮 / 房产 / 其他 | 都问 |
| 1b | 产品/服务/资料包**名字** | 短填 | 打字（如「28 天美白疗程」）。🔴 B 闸门页：这个名字＝封面＝资料包＝页面标题，**三处必须一致** | 都问 |
| 2 | 卖给**谁**？`[读md或问]` | 选择 | 老板 / 打工人 / 宝妈 / 学生 / 副业者 / 专业人士 / 其他 | 都问 |
| 3 | 他们最**痛**什么？（按行业自动给 6 条，勾 2–3） | 多选 | 〔依 Q1 行业动态列出常见痛点〕 | 都问 |
| 4 | 你靠什么**解决**？ | 选择 | 独家方法/配方 · 更快更省 · 一站式 · 有保障售后 · 专业资历 · 其他 | 都问 |
| 5 | **包含**什么？ | 多选 | 产品 · 课程 · 咨询 · 售后 · 赠品 · 保证 | 都问 |
| 6 | **价格** / 原价 / 优惠 | 短填 | 打数字（现价 / 原价 / 折扣） | 🔴 **只有 A（和收费的 C）才问** |
| 7 | 用哪种**紧迫感**？ | 选择 | 名额有限 · 限时优惠 · 早鸟价 · 数量限量 · 不写 | 🔴 **只有 A / C 才问**（B、D 不问） |
| 8 | 有**真实见证**吗？ | 选择+短填 | 有（贴 名+一句）/ 暂时跳过 | 都问 |
| 9 | 按钮点了**去哪**？ | 选择 | WhatsApp / Google 表单 / AutoCRM 原生 form / 社群邀请链接 | 都问 |
| **9b** | 🔴 **那个链接是什么？**（实际值） | 短填 | WhatsApp 号码（去 0 加 60）／表单链接／群邀请链接。**没有就先给占位，并告诉他之后要换哪一行** | 都问（跟 9 连着问，别只问「去哪」不问「去哪里的哪里」） |
| **10a** | **底色**要深还是浅 `[读md或问]` | 选择 | 浅色（奶油／白底，干净好读）· 深色（黑底，科技感）· 照品牌 md 的底色 | 都问 |
| 10b | **主色** `[读md或问]` | 选择 | 读 md 品牌色 / 主题(SUMA 蓝 · 暖橙 · 黑金 · 清新绿 · 玫红) / 自填色号 | 都问 |
| **11** | 🔴 页面用**哪种语言/字体** | 选择 | 简体中文 · 繁体中文 · 中英混（术语留英文）· 英文 · 马来文 | 都问 |
| **12** | 🔴 成品**放哪**（本机） | 选择 | 业务档案里那个成品 folder · 指定一个 folder（打字）· 先放暂存区之后再说 | 都问 |
| **12b** | 要不要顺便**贴进 Notion／传 Drive** | 选择 | 都要 · 只贴 Notion · 只传 Drive · 都不用 | 都问 |

> `[读md或问]`：先读 01-branding 的品牌 md，读到就用、不问；读不到才问。
> 🔴 **「何时问」写「都问」的，一题都不准漏**（见铁律 2b）。写条件的那几题，不适用时要**讲一句为什么不问**。

> 拿到答案后：用行业+受众挑对人性需求；痛点套 PAS；价格套原价锚定+换框；见证套社会认同；CTA 套未来预演。**每个区块都要能说出「套了哪个大师/NLP/需求」，说不出＝没做到位。**

### Step 2.5 · 🔴 先出 hero 样张给他看（确认了才铺全页）

**别一口气铺完整页再给他看** —— 配色不对／标题不对，整页要重来，他也会觉得「不是我要的」。

1. 只生成 **hero 首屏一段**（顶部 + 主标 + 副标 + CTA 按钮 + 配色），存成一个小 html。
2. **开预览截图给他看**（不要只贴 code 叫他想像）。
3. 问一题：**「配色和标题这样对吗？」**（① 就这样往下铺 ② 换配色 ③ 换标题写法 ④ 两个都改）
4. 他说 OK 才进 Step 3 铺全页。改的话就地改 hero 再看一次。

🔴 **问超过 3 轮还没给他看到任何画面 ＝ 违规**（跟 `ai-carousel` 同一条规矩）。

### Step 3 · 生成两版页面

照 **Step 0c 选到的页型**挑对应那份蓝图（A 销售／B 闸门／C 活动／D 预约，见下方「页面蓝图」）组装，套 Step 2 的答案 + Step 1 的图（压缩内嵌），一次吐**两个文件**：
- `你的LP-autocrm片段.html`（贴 AutoCRM）
- `你的LP-独立页.html`（直接上线）

## 🗺️ 页面蓝图（四份 · 照 Step 0c 的页型挑一份）

🔴 **不要每张页都套销售页那份。** 页型不同，区块顺序和有没有价格区都不一样。

### A 销售页蓝图（`templates/base.html`）

| 区块 | 内容 | 套了谁 |
|---|---|---|
| **0 顶部 header** | logo（或纯文字品牌名） | — |
| **1 Hero 首屏** | 主标（把顾客的处境/渴望讲出来）+ 副标 + 主视觉 + CTA | Blair Warren 正名 · 连续认同 |
| **2 痛点** | 勾选的 2–3 个痛点，写成具体画面（不是形容词） | PAS（Problem·Agitate）· 自我说服 |
| **3 方案登场** | 你的产品/服务怎么解决 | PAS（Solution）· 换框 |

### B 闸门页蓝图（`templates/blueprint-gate.html`）—— 免费资料包换名单

| 区块 | 内容 | 套了谁 |
|---|---|---|
| **1 Hero** | 🔴 主标＝**资料包的名字**（封面／资料包／页面标题三处一字不差）+ 副标（先为他的处境正名）+ 主视觉 + CTA | Blair Warren 正名 · 未来预演 |
| **2 痛点 ×3** | 同销售页，但第三格放**代价**（花的钱／时间），用人人懂的单位 | PAS · 自我说服 |
| **3 方案登场** | 敌人指向**错误的方法**，不怪他；可放 Before→After 对照图 | PAS(Solution) · 换框 |
| **4 你会拿到什么 ×4** | 逐项列交付物；🔴 **最后一格固定是「进社群」** | Duarte 客户是英雄 |
| **5 这份是怎么来的** | ❌ 不做价值堆叠、不估价、不锚定 → ✅ 换成**真实成本**（跑了几版／烧了多少／留下几条），最后一行「你要花的 = 0」 | 对比（但用成本不用价格）· 互惠 |
| **6 关于我** | 照片 + 你是谁 + 凭什么讲这件事 + **为什么免费给**（不讲动机他会觉得后面有坑） | 权威 · 喜好 |
| **7 表单** | 姓名 ＋ email ＋ WhatsApp（三格是默认，可按他答的加减） | 嵌入指令 ·「因为」催化剂 |
| **8 CTA 收尾** | 未来预演一句 + 大按钮 | 未来预演 · 预设 |

🔴 **闸门页红线**：免费的东西**不做假限时／假名额**；不承诺成果；作者区的照片必须是真人真照。

### C 活动报名页蓝图

`1 Hero（标题 + 🔴 日期·时间·线上/线下）→ 2 为什么该来（痛点）→ 3 你会学到什么（议程，一条一格）→ 4 讲师是谁（照片+资历）→ 5 谁适合来／谁不适合 → 6 报名表单 → 7 CTA`
· 免费场**不放价格**；收费场才放价格区。紧迫感只写真的（真名额／真截止）。

### D 预约咨询页蓝图

`1 Hero（我帮你解决什么）→ 2 痛点 → 3 我怎么做（方法/流程）→ 4 案例（有真数据才放）→ 5 🔴 打消顾虑区（聊什么·要多久·会不会被硬销·收不收费）→ 6 预约时段/WhatsApp → 7 CTA`
· ❌ 不放价格、不做价值堆叠 —— 高单价是聊出来的，页上标价会把人挡掉。

## 📦 输出规格（两版怎么做）

**同一份内容，两个外壳：**

| 版本 | 外壳 | 按钮怎么收 lead |
|---|---|---|
| **AutoCRM 片段** | 以 `<style>` 开头，**无** doctype/head；CTA 处留 `<!-- ★ 在此插入 AutoCRM 原生 form -->` | 贴进 AutoCRM，用**原生 form**（真进 CRM） |
| **独立页** | 完整 `<!doctype html>` + `<head>`（charset/viewport/title）；能双击打开、能上线 | 按钮 = **WhatsApp（wa.me/号码）** 或 Google 表单链接（无后台） |

**共同规格：**
- 图片：压到长边 ~900px、webp、每张 ~40KB，**base64 内嵌**（两版都自包含）。
- 响应式：手机优先，宽的表格/图自己横向滚动。
- 品牌色：用 Step 2 选的主题套 CSS 变量。
- 视频：不内嵌，用 `<video>` 贴链接 或 放一张封面图链去 YouTube。

> 👉 **独立页故意只导去 WhatsApp/表单 = 天然的桥。** 想要真正的 CRM 收单、自动跟进、后台 dashboard？那就是下一课。

## 📚 前置背景 · 落地页成交心法（生成前必读 · 全嵌入 · 每次都套）

> 这一段是**页面说服力的根**。生成任何一个区块前，先想「这块套哪个大师 + 哪个 NLP + 戳哪个需求」。说不出＝只做了表面，重来。
> 这是从 SUMA 跑过 90+ 条广告验证出来的底盘，**行业通用**——换成学员的产品/受众，心法不变。

### ① 文案大师（灵魂 · 每个区块至少套 2 个）

- **为顾客的处境正名（Blair Warren）—— 落地页的灵魂，hero + 痛点几乎必用。**
  他做不好/买不到理想结果，**不是他的错**——是市场/旧方法的问题。把「共同的敌人」指向**错误的方法或环境**，不怪顾客。
  > 例：「不是你的产品不够好，是没人帮你把『为什么该选你』讲清楚。」
- **让顾客自己说服自己（Self-Persuasion）—— 最强的说服是他自己得出的结论。**
  用「你是不是也…？」「算算你一年花多少…？」让他自己发现问题、自己算账。
- **LF8 生命原动力（Drew Whitman）**：生存 / 免于恐惧 / 被认同 / 优越感 / 舒适 / 爱护家人 / 被接纳 / 性。**钩子戳本能，不是戳功能**（「怕被落下」比「功能很强」有力）。
- **结构套 PAS 或 AIDA**：落地页整体走 **PAS**（Problem 痛点 → Agitate 放大 → Solution 方案）最顺；BoFu 区块用 **AIDA**（注意→兴趣→欲望→行动）。
- **Cialdini 影响力**：**社会认同**（真实见证）· **稀缺**（名额/限时）· **对比**（原价 vs 现价）· 权威（资历）· 喜好。一个区块挑 1–2 个。
- **卖 ROI 不卖功能（Belfort）**：讲**结果的反差**（before→after 真数字），不列产品参数。
- **顾客是英雄，你是向导（Duarte）**：页面里**顾客是主角**，品牌是递地图的向导，不是站 C 位的救世主。

### ② NLP 语言模式（挑 1–2 个植入对应区块）

| 技巧 | 原理 | 用在页面哪 | 例 |
|---|---|---|---|
| **未来预演** | 让他先在脑中体验拥有结果的那天 | CTA / hero | 「想象下个月，你的页面每天帮你收单，你只管回复。」 |
| **换框** | 同一件事换个框，意义就变 | 价格区 | 「这不是花费，是一次性买下一个永远能用的成交页。」 |
| **连续认同（Yes-Set）** | 先让他连点几个头 | 标题 / 痛点 | 「内容重要吧？没时间做吧？请人贵吧？——所以你需要…」 |
| **锚定** | 用高价先定锚，再给现价 | 原价删除线 | 「原价 RM2,980 ~~划掉~~ → 今天 RM___」 |
| **预设** | 把想让他接受的当成已成立的前提 | CTA | 「你**开始用**之后，第一个想卖的产品是哪个？」 |
| **嵌入指令** | 把动作藏进自然句里 | 按钮上方 | 「当你**现在就填下面这张表**，就离成交更近一步。」 |
| **对比框** | before 惨 / after 爽 并排 | 痛点→方案 | 「以前：一条一条手打页面。现在：答几题，页面自己出来。」 |
| **「因为」催化剂** | 给个理由，答应率就升 | 紧迫句 | 「现在就报名，**因为**趁早用趁早领先。」 |

### ③ 6 大人性需求（按行业+受众自动挑主需求）

| 需求 | 在追求 | 落地页怎么戳 |
|---|---|---|
| **确定感** | 不出错、不被骗 | 保证、售后、真实证据、步骤清单 |
| **成长** | 变强、进步 | before→after、「升级你的…」 |
| **重要感** | 被看见、独特 | 专属/限量、身份认同 |
| **爱与连接** | 归属、被理解 | 共鸣故事、「原来不只我这样」 |
| **新鲜感** | 新奇、惊喜 | 反直觉、「你没想到的做法」 |
| **贡献** | 利他、有意义 | 使命、「帮到更多人」 |

> **搭配口诀**：确定/成长 → 最搭方案区+见证区；重要/新鲜 → 最搭 hero；爱与连接 → 全页都能加温度。

### ④ 价值堆叠 + 原价锚定（价格区专用打法）

1. 把交付物**逐项列出来**，每项标一个「单买大概值多少」（诚实估，不虚标）。
2. 加总 → 得出一个**总价值**（远高于售价）。
3. 售价用**原价删除线 → 现价**呈现，落差越清楚越有力。
4. 紧接**稀缺句**（真名额/真限时；没有就不写）。
> 这套 = Cialdini 对比 + 锚定 + 换框三合一，是落地页价格区最会成交的结构。

### ⑤ 护栏（心法之上，红线不破）

- **真实第一**：能说的价值放大、说；做不到的**绝不承诺**。
- **假的都不碰**：假见证、假数字、假成果、假紧迫（没名额别写数字）、假产品图、假人脸。
- **学员自己的生意**：报价/限时/优惠是他的商业自由（**不套 SUMA 招生的合规房规**）。
